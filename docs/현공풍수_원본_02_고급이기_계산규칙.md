**표기 규약**

- 궁 낙서수: 감1 곤2 진3 손4 중5 건6 태7 간8 리9
- 비행 순서(offset): 중0 → 건1 → 태2 → 간3 → 리4 → 감5 → 곤6 → 진7 → 손8
- `순비: 값 = 입중수 + off(궁)` / `역비: 값 = 입중수 − off(궁)` (1~9 정규화)

### 1-5. 알고리즘 (의사코드)

```python
def chart(period, sit, use_ti):
    yun   = fly(period, forward=True)          # 운반: 운수 입중 무조건 순비
    sp    = palace_of(sit); fp = 10 - sp        # 좌궁, 향궁(대궁)
    yuan  = yuan_of(sit)                        # 0=지 1=천 2=인 (좌·향 동일)
    a, b  = yun[sp], yun[fp]                    # 운반 산성수 / 향성수

    # 대응산 결정 (5입중 특칙 포함)
    ms = MOUNTAIN[period if a == 5 else a][yuan]
    fs = MOUNTAIN[period if b == 5 else b][yuan]

    sd, fd = is_yang(ms), is_yang(fs)            # 순역은 항상 '대응산'의 음양

    if not use_ti:                               # 하괘
        sc, fc = a, b
    else:                                        # 체괘
        sc = a if a == 5 else TI[ms]             # ★ 5는 無替
        fc = b if b == 5 else TI[fs]

    return fly(sc, sd), fly(fc, fd)
```

**핵심 3원칙**

1. 체성 조회 대상은 **좌·향 글자가 아니라, 운반성이 가리키는 궁에서 좌·향과 같은 원룡인 산**이다.
2. **순역은 체괘에서도 바뀌지 않는다** — 대응산의 원래 음양 그대로.
3. **운반성이 5일 때는 체성이 없다**(염정 무체). 5를 그대로 입중하고 음양만 5입중 특칙으로.
   - 원문: "5입중 이후 대응하는 중궁은 갈아끼울 것이 없으니, 여전히 건축의 원룡 성질로 음양을 정한 뒤 순배·역배를 확정한다"
   - 5입중 음양 특칙의 두 표현("운수 궁의 동일 원룡 산" / "좌·향 글자 자체")은 **수학적으로 항상 같은 결과**를 낸다. 운반에서 5가 놓인 궁과 운수 궁은 반드시 대궁(합십) 관계이고, 대궁은 홀짝 패리티가 같아 동일 원룡의 음양이 일치하기 때문.

> ⚠️ **정정**: "향과 삼반괘 관계인 궁이 정성문"이라는 설명은 성립하지 않는다. 낙서 팔방 순환(감1–간8–진3–손4–리9–곤2–태7–건6)에서 **인접 두 궁은 결코 같은 삼반괘 조가 될 수 없다.** 삼반괘 관계 궁은 인접이 아니라 격궁(리·건·진 / 감·손·태 / 중·곤·간)이며, 그쪽은 칠성타겁의 골격이다.

### 2-3. 성립 조건 알고리즘

```
1. face = 좌산의 대충 산, fe = face의 원룡(지/천/인)   ← 동원일기
2. fp   = face가 속한 궁 → (정성문, 부성문) 결정
3. for g in (정성문, 부성문):
       X = 운반성(g)
       if X == 5: 대응궁 없음 → 판단 유보(암성문 논의)
       기준산 = 낙서 X궁의 fe번째 산     # 향과 동원
       방향   = 양이면 순비, 음이면 역비
       V      = fly(X, 방향)[g]
       성립 ⟺ V == 당운수
```

**수학적 단순화** ✅: 궁 낙서수 n, d=off(n)일 때 운반성 X = 運+d.
- 순비면 V = 運+2d → **d=0(중궁)일 때만 성립하므로 사실상 절대 불성립**
- 역비면 V = 運 → **항상 성립**

> **성문 성립 ⟺ 그 궁의 운반성이 가리키는 대응궁에서 향과 동원인 산이 음(역비)일 것.**
> 입중·비포 없이 **음양만 보면 끝난다.**

### 2-6. 실무 의미와 이견

- 성문 방위에 **득수·수구·대문·주출입구·차량 진입로·십자로·골목 입구** 배치. 좌산 좌우의 수봉·고층·문창탑도 광의의 성문.
- 왕산왕향이면 배가, **상산하수·좌향 불량이면 열세를 반전**시키는 보조법.
- **당운 한정** — "성문일결은 오직 당왕할 때만 쓸 수 있어, 당왕이면 즉시 발하고 운이 지나면 곧 패한다." 20년마다 재점검.
- **동원일기 필수**: 천원룡 향이면 성문도 천원룡.
- 금기: 쇠사(衰死)의 성이 성문에 배열되면 흉.
- ⚠️ **정성문 판별**: 하도 생성수설(주류) vs 성문궁의 운성과 낙서수가 생성수를 이룰 때를 별도의 **암성문**으로 보는 설이 병존.
- ⚠️ **운반성 5가 성문궁에 올 때**: cafengshuinet은 "동원일기 조건 충족 시 암성문으로 사용 가능", pixnet 예제는 순비 처리해 불성립 — **미해결**.
- **담양오 현공육법**은 5황을 대금룡으로 삼고 영신 방위 개념으로 성문을 보므로 **비성파 산법과 혼용 불가**.
- 국내 학술논문(KCI 「현공 풍수의 역사와 이론구성의 비판적 고찰」)은 성문결·칠성타겁의 실체가 명확히 규명되지 않았다고 지적.

### 4-2. 판정 규칙 ✅

| 유형 | 판정식 | 개수 |
|---|---|---|
| (a) **전국 복음** | `입중수 == 5 and 순비` → 전 궁 `성수 == 낙서수` | **24국** |
| (b) **전국 반음** | `입중수 == 5 and 역비` → 전 궁 `성수 + 낙서수 == 10` | **24국** |
| (c) 궁위 복음(원단반형) | 어느 궁에서 `산성 or 향성 == 그 궁 낙서수` | 수시 |
| (d) 궁위 복음(운반형) | 어느 궁에서 `산성 or 향성 == 그 궁 운성` | 수시 |
| (e) 궁위 반음 | 어느 궁에서 `산성 or 향성 + 낙서수 == 10` | 수시 |
| (f) 괘 반음·복음 | 선천64괘 착괘(반음)/종괘(복음) 대조 | 아래 |

5순비 = `중5 건6 태7 간8 리9 감1 곤2 진3 손4` = **원단반 그대로**
5역비 = `중5 건4 태3 간2 리1 감9 곤8 진7 손6` → **전 궁 합십**

**정정 2가지**
1. 성반이 **운반과 전면 일치하는 "전국 운반복음"은 하괘에서 불가능**하다(산성 입중수 = 운반[좌궁] ≠ 운수). 운반형 복음은 궁위 단위로만 발생.
2. 성반이 **운반과 전국 합십**하는 경우는 반음이 아니라 **「합십」 길격**이다. 반음은 어디까지나 **원단반(낙서) 기준**.

**(f) 괘 반음·복음 절차**: 좌산궁·중궁·향수궁의 (향성=상괘, 산성=하괘)로 괘를 조성(5는 운성으로 대체) → 복음은 종괘(효 순서 뒤집기), 반음은 착괘(전 효 음양 반전) → 나온 괘명이 나경의 해당 좌산/향수 아래 64괘 범위에 있으면 그 도수를 피한다.
🚫 **나경 선천64괘의 24산 배당표 전체를 확보하지 못해 코드 구현 불가.**

### 4-3. 전수표 ✅

**전국 복음 24국** (좌향 12개 × 각 2운)
임병·병임 (1·9운) / 간곤·곤간·인신·신인 (2·8운) / 갑경·경갑 (3·7운) / 손건·건손·사해·해사 (4·6운)

> ⚠️ cafengshuinet은 "임산병향 1운, 향성 반음"이라 적었으나 임·병은 둘 다 지원 양이므로 5입중 시 순비 → **복음**이 맞다.

### 4-4. 검산 예시 (셀 = `산 운 향`)

**7운 을산신향 — 산성 5입중 역비 = 전국반음 + 왕산왕향**

간(향) 8 2 5   감 1 4 7   건 6 9 3

### 5-2. ★ 중요 — "삼궁이 삼반괘를 이룬다"는 조건은 항등식 ✅

입중수 c에서 리→c+4, 건→c+1, 진→c+7 ⇒ {c+1, c+4, c+7}은 **항상** 3씩 차이 = 항상 삼반괘 조. 감·손·태도 {c+2, c+5, c+8}로 마찬가지. 역비도 동일.
**216국 전부에서 이 조건이 성립**하므로 이 조건만으로는 아무것도 걸러내지 못한다. 실제 변별력은 **"어느 삼반괘 조인가(= 당운 왕성이 향수에 오는가)"**에 있다.

### 5-3. 판정 규칙

```
1. 향수궁: 향이 병/오/정(리궁) → 리궁타겁 = 진타겁 후보
           향이 임/자/계(감궁) → 감궁타겁 = 가타겁 후보
           그 외 → 심씨 정의상 불성립
2. 당운 왕성이 산반·향반 모두 향수에 도달 = 쌍성회향
3. 복음을 범하지 말 것 — "칠성타겁불가용복음"
4. 형기: 타겁 삼궁이 트여 있고 문·창·통로로 통기할 것
```
진/가 구분 근거: **"북두위제성, 제출호진, 상견호리, 전호건"** — 제성의 궤적이 진→리→건이므로 리궁 쪽이 진짜.

## 7. 입수(入囚)와 지운(地運)

### 7-1. 정의 📖

**"영성입중궁위지수"** — 당령성이 중궁에 갇혀 팔방으로 작용을 펴지 못하는 상태.

### 7-2. 계산 규칙 (정향·하괘 표준) ✅

```
향성 입수운 V = 운반[향수궁] = 중궁 향성수
산성 입수운 S = 운반[좌산궁] = 중궁 산성수
지운(년)     = 20 × ((V − R) mod 9)      # R = 건축 운
입수 개시년   = V운의 시작 연도
운 시작연도: 1운1864 2운1884 3운1904 4운1924 5운1944 6운1964 7운1984 8운2004 9운2024
```

**핵심 도출** ✅: `운반[향수궁] = R + off(향궁)` 이므로 `(V−R) mod 9 = off(향궁)`
⇒ **지운은 건축 운과 무관하게 "향이 놓인 궁"만으로 결정된다.** (엔진 전수 확인, cafengshuinet 24산 지운표와 8/8 일치)

|---|---|---|
| 건 | 진산술향 손산건향 사산해향 | **20년(최단)** |
| 태 | 갑산경향 묘산유향 을산신향 | 40년 |

### 8-1. 사실 확인 ✅

### 8-2. 수학적 원인 ✅ — 유파 해설보다 정확

좌궁 낙서수 L, k=off(L)라 하면 향궁 offset은 −k. 9운(운반 9입중 순비)에서 좌·향의 운반성 a, b는 **항상 a + b = 9**(a=b=9는 9가 중궁에만 있으므로 불가).

삼원룡 음양은 **궁의 홀짝만으로** 결정된다.
- 천원·인원: 홀수궁(1·3·7·9) → 음(역비) / 짝수궁(2·4·6·8) → 양(순비)
- 지원: 홀수궁 → 양(순비) / 짝수궁 → 음(역비)

`a + b = 9`(홀수)이므로 **a와 b는 반드시 홀·짝이 갈린다** ⇒ 산성반과 향성반의 비행 방향이 **항상 서로 반대** ⇒ 왕산왕향(둘 다 역비)·상산하수(둘 다 순비)는 **구조적으로 불가능**.
※ a=5인 경우도 5입중 특칙으로 운수 9(홀수궁)를 따르므로 홀수 취급, 규칙 그대로 성립.

**1운도 동일**(a+b=11, 홀수) — 24국 전부 쌍성.
**대조군 8운**: 건손축만 a+b=16(짝수, 7+9/9+7)이라 같은 방향이 되어 **왕산왕향과 상산하수**가 나온다.

### 8-3. "전국 합십으로 보구한다"는 통설 검증 ✅

통설: "배진구궁구운이백일십육도, **유유일운화구운몰유왕산왕향지국**, 저취요채용**전국합십**래보구 … 유어전국합십, 즉사불시왕산왕향, 역유왕산왕향지공효."

6. **9운에 부모삼반괘·연주삼반괘는 하나도 없다**(부모삼반은 2·5·8·4·6운, 연주삼반은 2·3·5·7·8운에만)
