# 현공풍수(玄空風水) 조사

> 작성 2026-08 · Destiny Code 나경(현공비성 탭) 배경 자료.
> 산법 구현·검증 내역은 `frontend-next/src/lib/flyingStars.ts` 주석 참고.

---

## ⚠️ 용어 구분 — 형기풍수와 혼동 금지

| | **형기풍수(形氣風水)** | **현공풍수(玄空風水)** |
|---|---|---|
| 계열 | 형세파(巒頭派) | **이기파(理氣派)** |
| 보는 것 | 눈에 보이는 **산세·물길·지형**(용혈사수) | **수리(數理)와 방위** — 낙서 구성의 비포 |
| 시간 개념 | 없음(명당은 불변) | **있음(20년 운마다 길흉 변동)** — 핵심 차별점 |
| 도구 | 눈·경험(간산) | 나경(좌향 측정) + 비성반 계산 |

- "현기풍수"라는 독립 유파는 확인되지 않음. 형기(形氣)를 지칭하는 경우가 대부분이므로 혼동하지 말 것.
- 현공풍수 자체도 "먼저 형기(지형)를 보고, 그 위에 이기(비성)를 얹는" 것을 원칙으로 한다(형리합일). 즉 형기를 대체하는 게 아니라 **형기 위에 시간축을 추가**한 이론.

---

## 1. 개요

현공풍수는 **시간(運)과 공간(方位)을 결합해 터의 길흉을 수(數)로 읽는** 이기풍수의 대표 유파. 핵심 명제는 **"같은 집도 시대(운)가 바뀌면 길흉이 바뀐다"**(지운地運 개념). 삼합풍수와 함께 이기파의 양대 축이며, 현재 홍콩·대만·싱가포르 풍수의 사실상 표준.

## 2. 역사·계보

| 시기 | 인물 | 내용 |
|---|---|---|
| 당(唐) | 양균송(834~900) | 『천옥경』『청낭오어』『도천보조경』 — 이론의 연원. 이후 천 년간 사제 간 비전(祕傳) |
| 청(淸) | 장중산(章仲山) | 무상파(無常派) 종사. 『음양이택록험』『지리변정직해』 등 실전 감정 기록 |
| 청말 | 심소훈(沈紹勳) | 장중산 계열 비전을 역추적·체계화 |
| **1925** | 심조면(심소훈 아들) | **『심씨현공학(沈氏玄空學)』 출판 — 비전 최초 공개**, 대중화의 기점. 오늘날 표준 산법의 근간 |
| 민국 이후 | 담양오(談養吾)·공소소 등 | 『대현공로투』 등 분파 발전(육법파 등) |

## 3. 핵심 이론

### 삼원구운(三元九運)
- 180년 = 상원·중원·하원 × 60년, 다시 20년씩 **9개 운**.
- 1864년 갑자를 상원 1운 기점으로 20년 주기. **현재 9운(九紫運): 2024~2043** — 화(火)·리(離)괘 시대.

### 비성반(飛星盤)
- 입력: **좌향 + 조성(입주) 시기의 운**.
- 운반(運盤): 운수를 중궁에 넣고 낙서 순서로 순비.
- **산성(山星, 인정·건강)**: 좌궁의 운반수 입중 / **향성(向星, 재물)**: 향궁의 운반수 입중.
- 순/역비는 24산 **삼원룡(지원·천원·인원)의 음양**으로 결정. 5 입중 시 좌·향산 자체 음양(특칙).

### 격국 4형 (당운수 위치)
| 격국 | 판정 | 의미 |
|---|---|---|
| 왕산왕향(旺山旺向) | 산성 당운=좌궁, 향성 당운=향궁 | 최길 — 정재양왕(丁財兩旺) |
| 상산하수(上山下水) | 산성 당운=향궁, 향성 당운=좌궁 | 최흉 — 손정손재 |
| 쌍성회향(雙星會向) | 산·향성 당운 모두 향궁 | 재왕정쇠 |
| 쌍성회좌(雙星會坐) | 산·향성 당운 모두 좌궁 | 정왕재쇠 |

- 단 **지형이 받쳐야 성립**(형리합일): 왕산왕향도 "뒤에 산·앞에 물"일 때 참됨.

### 구성(九星) 상의
| 성 | 오행 | 대표 상의 | 9운 기준 |
|---|---|---|---|
| 1白 탐랑 | 水 | 관운·지혜·인연 | 생기 |
| 2黑 거문 | 土 | 질병·모친 | 쇠살 |
| 3碧 녹존 | 木 | 시비·구설 | 쇠살 |
| 4綠 문곡 | 木 | 학업·문창 | 쇠살 |
| 5黃 염정 | 土 | **오황살(최흉)** — 동토·재앙 | 쇠살 |
| 6白 무곡 | 金 | 권위·부친 | 쇠살 |
| 7赤 파군 | 金 | 도난·구설 | 쇠살 |
| 8白 좌보 | 土 | 재물 | 퇴기 |
| 9紫 우필 | 火 | 경사·발전 | **당운 왕기** |

- 생기 판정 관행: 당운 다음 두 운(9운이면 1·2)을 생기로 봄. 구현은 1운을 생기로 표기(2黑은 병부성이라 실무에선 생기로 안 씀 — 해석 시 주의).

### 실전 원칙
- **"산성은 산을, 향성은 물을 만나라"** — 향성 왕·생기 방위에 물·도로·출입문(동적 요소), 산성 왕·생기 방위에 산·높은 가구·침실(정적 요소).
- 반대 배치(산성이 물에, 향성이 산에)는 흉. 오황·이흑 방위는 공사·침상 회피.

## 4. 삼합풍수와의 차이

- **삼합**: 방위 고정 길흉(수구→4국 포태) — 시간 불변.
- **현공**: 길흉이 **20년마다 변동** — "언제 지었나/입주했나"가 필수 입력. 9운 진입(2024)으로 "9운 좌향 선점" 실무 담론 활발.

## 5. 비판적 관점

- KCI 논문 「현공풍수의 역사와 이론구성의 비판적 고찰」 등 학술 검토 존재.
- 쟁점: ① 1864 갑자 기점의 임의성 ② 분파 간 산법 차이(심씨현공 vs 담씨육법 — 시간체계 2종 연구도 있음) ③ 검증 곤란성.
- → 앱 화면에 "현공비성 기준이며 유파에 따라 해석이 다를 수 있음"을 명시한 이유.

## 6. 앱 구현 현황

**구현·검증 완료** (`lib/flyingStars.ts` 외):
- 삼원구운(연도→운), 비성반(산성·향성·운반), 격국 4형, 왕생퇴살 색 구분 — 문헌 표준 11개 좌향 전수 일치
- **실전 감정 사례 대조** — 실무 감정 필기(2026.2.4, 수원 아파트 3건: 9운 丑坐未向·壬坐丙向·甲坐庚向)의 손그림 비성반과 **전 궁 100% 일치** 확인
- **연자백(年紫白)** — 1864 갑자(1白) 기점 매년 역행, 입춘 기준. 검증: 2024=3碧, 2025=2黑(오황 북동), 2026=1白(오황 남). 9궁에 연성 표시 + 오황·이흑 주의 방위 안내
- **성요 조합 해석** — 2·5 질병, 5·5 대흉, 2·3 투우살, 6·7 교검살, 7·9 화재, 1·4 문창, 1·6 문무귀인, 8·9 생왕 등 통용 조합표
- **팔택 통합** — 저장 명식의 본명괘 팔성을 9궁에 병기, "팔택 길성 ∩ 향성 왕·생기" 교집합 추천
- **좌향 각도 입력** — 팔택 나경 탭에서 잰 방위각을 입력하면 좌산 자동 판정
- **AI 현공 풀이** — 비성반 데이터를 서버로 보내 스트리밍 해석(격국·배치·올해 주의 방위)

**공망 경계 정밀표** (실전 경계표 반영, `lib/eightMansions.ts` voidCheck — 24행 전수 검증):
- 팔괘 경계 8곳(계축·인갑·을진·사병·정미·신경·신술·해임) = **대공망, 폭 6°**
- 지지·천간 경계 및 지지→사유 경계 = **소공망, 폭 3°**
- 사유→지지 경계 4곳(간인·손사·곤신·건해) = **소공망, 폭 1°**

**실전 감정 관행**(필기 사례에서 확인):
- 향성 왕기(당운수)가 있는 방위에 **베란다(개구부)** 가 있으면 길 — 예: 丑坐未向 쌍성회향 → "베란다가 서남(향궁)에 있을 것"
- 반대로 쇠살 방위 베란다는 흉으로 판단

**남은 확장 후보**(미구현): 성문결(城門訣)·겸향(兼向) 애성 — 상급 기법, 유파 차이 커서 신중 필요. 월자백(月紫白)도 추가 가능.
