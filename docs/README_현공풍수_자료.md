## 3. 절대 하지 말 것

1. **형살(천참살·벽도살 등)을 현공 개념처럼 서술하지 않는다.** 형살은 형기풍수다.
2. **삼살·대장군·손 없는 날을 연자백 오황과 같은 화면에 섞지 않는다.** 2026년 정동·정북에서 판정이 정면 충돌한다.
3. **기두(起頭)로 현공 성반을 세우지 않는다.** 기두는 팔택 개념이다.
4. **선천팔괘 수(건1 태2 리3…)와 낙서 궁수(감1 곤2 진3…)를 섞지 않는다.**
5. **물품 처방을 원리인 양 말하지 않는다.** "오황에는 금속이면 된다"가 원리, "육제전"은 상술이다.
6. **검증되지 않은 계산(조신·최신·현공대괘)을 엔진에 넣지 않는다.**

## 4. 남은 미확인 항목

1. 나경 선천 64괘의 24산 배당표 — 괘 반음·복음 구현에 필수
2. 조신(照神)·최신(催神)의 확정 산출식 (3설 병존)
3. "반음복음화난당"의 고전 출전 — 『천옥경 내전』에 부재, 『도천보조경』 하편 설 대조 필요
4. 5운의 정신·영신 처리 (3설)
5. 반음과 복음 중 어느 쪽이 더 흉한가 (문헌 정면 충돌)
6. 지운 기산의 당운 포함 여부 (자료 내부에서도 ±20년 불일치)
7. **체괘반 기준의 삼반괘·타겁·반복음·입수** — 현재 검산은 전부 하괘 216국 한정
8. 4대 격국의 우열 서열을 순위로 제시한 1차 원문
