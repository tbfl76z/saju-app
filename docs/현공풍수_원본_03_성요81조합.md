# 상세자료 — 성요(星曜) 81조합 전표

> 학습 카드용으로 압축하기 전의 **원자료**. 감정·해석 시 참조용.
> 범례: **생입** = 나를 생함 / **생출** = 내가 설기됨 / **극입** = 극을 당함 / **극출** = 내가 극함
> **앞 숫자 = 산성(주체)**, 뒤 숫자 = 향성. 📖 = 고전 원문
> 검산: 조합 판정 자체는 계산이 아니라 문헌 해석이므로 **원문 인용을 함께 남긴다.**

## 1. 순서 문제 — 유파가 정면으로 갈림 ⚠️

### 순서 무관파

- 진욱훈: **"산·향의 수는 모두 같이 볼 수 있으니, 일사(1·4)든 사일(4·1)이든, 이팔(2·8)이든 팔이(8·2)든 논하는 바가 같다"**
- 유훈승 『음양학』: 조합을 「1.2.；2.1.同宮」처럼 쌍으로 묶고 **"이상은 산수가 자리를 바꾸어도 같이 논한다"**

### 순서 유관파 — 1차 사료 자체가 구분한다 📖

- 『자백결』: **"육팔은 무과로 발하니 병략으로 몸을 영화롭게 함에 벗어나지 않고, 팔육은 문사가 군에 종사하거나 다른 길로 발탁된다."**
- 『자백결』: **"칠이 삼을 만나면 재물이 생기나 재물이 많아 도둑맞음을 어찌 알겠는가. 삼이 칠을 만나면 병이 생기니 병이 나은 뒤 관재를 만남을 어찌 알겠는가."**
- 역경당: **"무릇 사팔을 말할 때는 사록을 주로 삼고, 팔백을 주로 삼으면 팔사라 한다"**(앞 숫자가 主) / **"칠팔 역시 부를 주관하나, 팔칠은 도리어 파재를 주관한다"** / **"음이 양을 극하면 산성은 병을 주관하고 향성은 파재를 주관한다"**

### 공통점

"순서 무관"을 주장하는 쪽도 **오행 생극 방향(생입/생출/극입/극출)은 앞 숫자를 주체로** 붙인다. 예: 1·2 = 극입, 2·1 = 극출.

### 실무 정리

1. 사건의 **종류**(살의 이름)는 대체로 순서 무관
2. **어느 영역에 나타나는가**(인정·건강 vs 재물)와 **주체가 누구인가**는 순서 의존
3. **6·8/8·6, 7·3/3·7은 원문 차원에서 명백히 구분**

> 『비성부』 원주가 **"편중에 64괘 이름을 빌려 산과 향의 비성을 이름 붙였다"**고 밝히므로, 조합 명명 자체가 상괘·하괘 = 순서 구조를 전제한다는 점이 순서 유관파의 유력한 근거다.

## 12. 운에 따른 길흉 반전 📖

『비성부』: **"왕한 것을 잇고 생하는 것을 이으면 얻어서 기쁘고, 쇠한 것을 만나고 물러남을 만나면 잃어서 근심스럽다."**
『자백결』: "왕생이 한 번 만나면 형통하고, 사퇴가 쌍으로 임하면 불리하다" / **"운이 이르면 어찌 천심을 근심하랴. 그러나 살성이 왕을 만나면 끝내 겁적을 당한다"**
『현공비지』: "길신이 쇠하고 기신이 왕하면 이는 방에 들어와 창을 잡는 것이다"

**별 상호 5분류**(역경당): **"별과 별이 만나면 생·왕·퇴·살·사 다섯 가지로 나눌 수 있다. 생왕은 길하고 퇴살은 흉하며 사는 길흉이 반반이다."**
예) 7금이 8토를 만나면 生, 6금을 만나면 旺, 1수를 만나면 退, 9화를 만나면 殺.

**구체 반전 사례**

| 조합 | 반전 규칙 |
|---|---|
| 7적 | 7운엔 왕. 단 **"이칠동궁이면 화국을 이뤄 화극금으로 왕해야 할 때 왕하지 못한다"** |
| 2·5 | "2운은 그런대로 괜찮으나 2운이 지나면 재앙과 사망이 즉시 발생한다" / **"이오가 생왕하면 의가에 크게 이롭다"** |
| 5·2 | 2운과 5운에는 큰 행운, 다른 운에는 과부·중병 |
| 1·9 | 9운이면 9자가 생왕하고 1백이 쇠수 → 극으로 인해 욕을 부르고 재물로 화를 부름. 1운이면 1백 생왕 + 1·9 합십 → **갑작스러운 부** |
| 4·1 | **1운**이면 4록이 쇠퇴해 1백의 생을 받으니 **총명한 탕자가 난다** |
| 3·4 | 3·4운엔 정재를 주관. 단 **8·9운이면 반대로 집을 기울이는 도적 자식** |
| 6·9 | 6백금이 **생왕지운** 안에서 9자화를 보면 반대로 가주의 공명과 장수를 주관 |
| 9·6+8 | 9자가 6백을 극해 파재손부이나 **8백이 또 보이면** 화토금 상생으로 반대로 큰 부 |
| 5황 | 5운에만 당령. **"왕할 때는 재정이 크게 발하고, 쇠할 때는 생하든 극하든 모두 대흉"** |

**하원 9운 기준 기(氣) 배속**: 9=당왕, 1=생기, 2=원생기 → **"2흑이 구성 중 흉성이라 하나 9운·1운·2운에서는 흉성이 크게 줄어든다."** 3~7 = 쇠기·살기.

## 13. 통관(通關) — 흉조합 해소의 이론 근거 📖

『현공비지』:

> **"목이 토를 상하게 해도 금의 자리가 겹겹이면 화가 있어도 구원이 있다.**
> **화가 금을 극해도 물의 신이 거듭 쌓이면 재앙이 침범하지 못한다.**
> **토가 물을 가두어도 목이 왕하면 무방하다.**
> **금이 목을 베어도 화가 밝으면 무엇을 꺼리랴."**

즉 흉조합이라도 **통관 오행이 겹치면 화(化)한다.** 역경당의 "9자가 6백을 극하나 8백을 또 보면 화토금 상생으로 도리어 호부"와 같은 논리다.

> **비보(화해) 설계의 이론적 근거가 바로 여기에 있다.** 우리 앱의 제화 로직은 이 원칙 위에 서야 한다.

## 14. 불확실 🚫

1. 81조합을 체계적으로 정리한 **한국어 공개 자료는 사실상 없다.** 본 정리는 전부 중국어·영어 자료 기반이며 한국어 명칭은 한자어 음독이다.
2. ⚠️ 『자백결』 이본 차이("이오교가이손주, 역차중병" vs "이오교가, 리사망병생질병"), 『비성부』 이문("건위색"/"건위한") — **판본 확정 안 됨**.
3. 순서 유관/무관 논쟁 — **미해결**. 다만 원문이 6·8/8·6, 7·3/3·7을 구분하는 것은 사실.
