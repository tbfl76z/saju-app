## 1. 대전제 — 고전이 말하는 것은 물품이 아니라 원리다

오늘날 유통되는 **"흉성별 전용 아이템 1:1 매칭표"라는 형식 자체가 현공 고전에 없다.** 현공 문헌이 규정하는 것은 ① 성요의 **오행·괘 배속** ② **동(動)/정(靜) 구분** ③ **오행 생극제화(五行 生剋制化)라는 추상 원리** 세 가지뿐이다.

### 1-1. 핵심 명제 📖

> 『자백결(紫白訣)』 하편
> **"흉살을 누르는 것은 풀어내는 것만 못하니, 종루와 고각은 국의 산이 생왕한 곳에 시공한다"**
> (制煞不如化煞為貴，鐘樓鼓閣，局山生旺施工)

> 『비성부(飛星賦)』
> **"칠은 강하고 삼은 굳세니, 강하고 굳센 것을 누르면 오히려 재앙이 난다"**
> (須知七剛三毅，剛毅者制則生殃)

> 『자백결』 하편
> **"운이 이미 물러났으면 염정이 만나는 곳마다 재앙이 하나가 아니니, 결국 피하는 것이 상책이다"**
> (運如已退，廉貞逢處眚不一，總以避之為良)

**우선순위: ① 피(避) → ② 설(洩) → ③ 극(剋, 권장하지 않음)**

### 1-2. 동(動)과 정(靜) — 자백결의 결정적 구분 📖

> **"왕궁에서 하나만 만나면 움직여야 재앙이 되고, 살처에서 거듭 만나면 가만히 있어도 사납다"**
> (旺宮單遇，動始為殃；煞處重逢，靜亦肆虐)

여기서 **오황(五黃)의 실무 원칙**이 나온다 — **의정(宜靜)**. 오황이 든 방위는 **건드리지 않으면 무방**하되, 자주 여닫는 문·선풍기·운동기구·공사처럼 **움직임을 만드는 것이 흉을 깨운다.**

> 실패 사례: 오황 자리에 **금속 운동기구**를 놓아 설기하려 했는데, 자주 사용하는 바람에 오황을 동적으로 활성화시켜 오히려 병에 시달렸다는 보고. **재질은 맞았지만 움직임을 만든 것이 문제**였다.

### 1-3. 건축 행위와 성요 방위의 연결 📖

> 『자백결』 하편: **"종루를 살지(煞地)에 세우면 가뭄을 자주 만날 뿐 아니라, 고탑을 화궁(火宮)에 지으면 생왕도 믿기 어렵다"**
> (建鐘樓於煞地，不特亢旱常遭；造高塔於火宮，須知生旺難恃)

**건축 행위와 성요 방위를 연결하는 논리는 현공 원문에 실재한다.** 다만 원문의 **"임방도간(臨方到間)"**은 **택내(宅內)의 방위·방**에 성요가 임하는 것을 말하며, 이를 "옥외 대지의 그 방향에서 터파기 금지"로 확장한 것은 **후대 통서·실무의 응용**이다. **원문에 "동토(動土)"라는 단어 자체는 확인되지 않는다.** 🚫

### 1-4. 인용 주의 🚫

오늘날 가장 널리 인용되는 **"고요해야지 움직이면 안 되고, 화해야지 극하면 안 된다(宜靜不宜動，動則終凶；宜化不宜剋，剋之則禍疊)"** 정형구는 **자백결 원문 대조에 실패**했다. 『유년구성단(流年九星斷)』 인용이라는 자료도 병존한다.

> **명제 자체는 (고전)이되, 인용 문구는 (미확인)**으로 다뤄야 정확하다. 인용할 때는 실재가 확인된 **"제살불여화살위귀"**를 쓴다.

### 1-5. 『자백결』 자체의 한계 🚫

**저자·연대 고증 불가.** 심죽잉(沈竹礽)이 『심씨현공학』에 수록할 당시에도 저자 불명이라 명기했다. **현행 현공비성 유년 방위론의 실질적 표준화 시점은 20세기 초(민국 초)**다.

### 2-4. 왜 오황·이흑에 금(金)인가 — 논리 사슬

1. 오황·이흑은 모두 **토(土)** 📖 — 자백결
2. 흉성은 **극하지 말고 화(설기)해야 함** 📖 — "제살불여화살위귀" / "강의자제즉생앙"
3. 토를 극하는 것은 목(木)이지만 **극이므로 배제**
4. 토를 설기하는 것은 **토생금(土生金)의 금(金)**뿐 → **금속이 유일한 정통 통로**

> **1~4가 현공 원리의 전부다.** "구리 동전 여섯 개(육제전)"라는 특정 물품 처방은 여기서 나오지 않는다 — **근현대 상술의 정형화**다.
> **정확한 표현: "오황에는 금속이면 된다."** ("육제전이어야 한다"가 아니다)

## 3. 하면 안 되는 제화 — 흉을 키우는 처방

전부 **현공 성요의 오행 배속에서 직접 도출**되는 것이므로 현공 순수 내용이다.

| 잘못된 처방 | 왜 틀렸나 |
|---|---|
| **오황·이흑 방위에 붉은색·자주색·조명·상야등·향·충전기** | **화생토(火生土)** — 흉한 토성에 화로 생조하면 흉성이 더 강해짐. **"금으로 설기해도 화가 함께 있으면 화해되지 않는다"** |
| **오황·이흑 방위에 황색·갈색·도자기·돌** | **비화(比和)** — 같은 토를 더해 흉성을 키움 |
| **오황 방위에 목(木)을 놓아 극(木剋土)함** | **극은 금기** — "강의자제즉생앙(剛毅者制則生殃)" |
| **삼벽 방위에 어항·수경식물·녹색** | **수생목(水生木)·비화** — 시비·관재를 조장 |
| **육백 방위에 붉은색·향·화로** | **화극금(火剋金)** — 길성인 무곡금을 극해 관운·권력운 손상 |
| **칠적 방위에 화(火)를 더함** | **"구칠이 길을 뚫으면 늘 회록의 재앙을 만난다(九七穿途，常遭回祿之災)"** — 화재 |
| **팔백(재성) 방위에 금속 과다** | **토가 설기됨** — 재성을 빼내 재운을 깎음. **길성에는 설기가 아니라 생조** |
| **오황 방위에 동(動)적인 것** — 자주 여닫는 문·선풍기·운동기구·공사 | 자백결 **"동시위앙(動始為殃)"**. 오황은 **의정(宜靜)** |

> **한 줄 요약**: 흉성에는 **설기**, 길성에는 **생조**. 방향을 거꾸로 하면 정확히 반대 효과가 난다.

## 4. 통관(通關) — 흉조합 해소의 이론 근거 📖

『현공비지(玄空秘旨)』

> **"목이 토를 상하게 해도 금의 자리가 겹겹이면 화가 있어도 구원이 있다.**
> **화가 금을 극해도 물의 신이 거듭 쌓이면 재앙이 침범하지 못한다.**
> **토가 물을 가두어도 목이 왕하면 무방하다.**
> **금이 목을 베어도 화가 밝으면 무엇을 꺼리랴."**
> (木傷土而金位重重，雖禍有救。火剋金而水神疊疊，災不能侵。土困水而木旺無妨。金伐木而火熒何忌)

즉 흉조합이라도 **통관 오행이 겹치면 화(化)한다.**

실무 사례: **"구자(九紫)가 육백(六白)을 극해 파재손부이나, 팔백(八白)을 또 보면 화토금 상생으로 오히려 큰 부를 이룬다"**

> **이것이 현공 제화 설계의 이론적 근거다.** 우리 앱의 제화 로직은 이 원칙 위에 서야 한다.

## 5. 운(運)에 따른 길흉 반전 📖

제화 판단이 고정되지 않는 이유다.

> 『비성부』: **"왕한 것을 잇고 생하는 것을 이으면 얻어서 기쁘고, 쇠한 것을 만나고 물러남을 만나면 잃어서 근심스럽다"**
> (承旺承生，得之足喜。逢衰逢謝，失則堪憂)

> 『자백결』: "왕생이 한 번 만나면 형통하고, 사퇴가 쌍으로 임하면 불리하다" / **"운이 이르면 어찌 천심을 근심하랴. 그러나 살성이 왕을 만나면 끝내 겁적을 당한다"**

> 『현공비지』: "길신이 쇠하고 기신이 왕하면 이는 방에 들어와 창을 잡는 것이다"

**별 상호 5분류**: **"별과 별이 만나면 생·왕·퇴·살·사 다섯 가지로 나눌 수 있다. 생왕은 길하고 퇴살은 흉하며 사는 길흉이 반반이다."**
예) 칠적금이 팔백토를 만나면 생(生), 육백금을 만나면 왕(旺), 일백수를 만나면 퇴(退), 구자화를 만나면 살(殺).

**구체 반전 사례**

| 조합 | 반전 |
|---|---|
| 칠적 | 칠운엔 왕. 단 **"이칠동궁이면 화국을 이뤄 화극금으로 왕해야 할 때 왕하지 못한다"** |
| 이·오 | "이운은 그런대로 괜찮으나 이운이 지나면 재앙과 사망이 즉시 발생" / **"이오가 생왕하면 의가(醫家)에 크게 이롭다"** — 약방·장의업 |
| 일·구 | 구운이면 구자 생왕·일백 쇠수 → 극으로 욕을 부름. 일운이면 일백 생왕 + 합십 → **갑작스러운 부** |
| 사·일 | **일운**이면 사록이 쇠퇴해 일백의 생을 받으니 **총명한 탕자**가 남 |
| 삼·사 | 삼·사운엔 정재를 주관. **팔·구운이면 반대로 집을 기울이는 도적 자식** |
| 육·구 | 육백금이 **생왕한 운**에 구자화를 보면 오히려 공명과 장수 |
| 오황 | 오운에만 당령. **"왕할 때는 재정이 크게 발하고, 쇠할 때는 생하든 극하든 모두 대흉"** |

**하원 구운(2024~2043) 기 배속**: 구자=당왕, 일백=생기, 이흑=원생기 → **"이흑이 구성 중 흉성이라 하나 구운·일운·이운에서는 흉성이 크게 줄어든다."** 삼벽~칠적 = 쇠기·살기.

## 6. 연자백(年紫白)·월자백(月紫白) — 시기 제화

### 6-1. 산출 ✅

**연자백 중궁수 = (1864 − 해당연도) mod 9 + 1** (1864년 일백 입중 기점, 매년 역행, 입춘 기준)

검산: (2026 − 1864) = 162, 162 mod 9 = 0 → **일백 입중**. 교차검증으로 1984년(하원 갑자) → 칠적 입중이 정설과 일치.
2026년 낙서 비포 결과 → **오황 = 리(離, 정남), 이흑 = 건(乾, 북서)**

### 6-2. 실무 원칙

- 그해 오황·이흑이 든 방위에서 **공사·이사·침상 이동을 피한다** (동/정 구분 원칙의 적용)
- 이미 있는 배치는 **건드리지 않으면 무방**
- 매년 방위가 바뀌므로 **연 단위 재점검** 필요

### 6-3. ⚠️ 절대 섞지 말 것 — 신살(神煞)과의 구분

**태세(太歲)·세파(歲破)·삼살(三煞)·대장군(大將軍)·손 없는 날은 현공이 아니다.**

| | 현공 연자백 | 신살 |
|---|---|---|
| 입력 | 삼원 180년 순환상의 연 순번 | 연지(12지지) |
| 주기 | **9년** | **12년**(대장군만 3년) |
| 방위 단위 | **팔괘 궁(45도)** | **24산(15도)** |
| 좌/향 구분 | **없음** | **있음** (태세는 좌 가능·향 불가, 삼살은 정반대) |
| 정본 | 『자백결』(민간 비전) | 『협기변방서』(국가 편찬) |

12와 9의 최소공배수는 36 — **수학적으로 독립된 변수**다. 방위 단위도 달라 **같은 지도에 그릴 수 없다.**

**2026년 실측 충돌**: 정동(卯)은 신살로 대장군방(대흉)인데 현공으로 팔백 재성(길). 정북(子)은 신살로 세파+삼살(대흉)인데 현공으로 육백(길). **합치면 논리 파탄이 난다.**
