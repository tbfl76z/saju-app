## 1. 좌향(坐向) 결정 — 최대 쟁점

현공 성반의 모든 것이 좌향에서 나오므로, 여기가 틀리면 이후 계산이 전부 무의미하다.

### 1-1. 견해 ① 대문(納氣門) 기준 — 고전 다수설 📖

> 『심씨현공학(沈氏玄空學)』: **"무릇 양택은 대문의 향이 받아들이는 기로 길흉을 판단한다"**
> (凡陽宅以大門向所納之氣斷吉凶)

**납기문(納氣門)의 3조건**
① 문 앞에 **명당(明堂)**이 있어 기가 모일 것
② 건물의 **총출입구**일 것
③ 건물 전체의 **입(口)**으로서 의미가 있을 것

**중주파(中州派) 실무**: 앞뒤 모두 발코니 문이 있는 집도 **입호문(入戶門)으로 입극하여 성반을 기동**한다. 논리는 **"문에 들어서 실벽을 마주하는 방향이 좌(坐), 나가서 내명당을 마주하는 방향이 향(向) — 빈 쪽에서 기가 오고 실한 쪽에서 기를 거둔다(空邊來氣, 實邊收氣)"**. 특히 **양쪽 다 발코니면 "빈 쪽에서 오는 기만 있고 실한 쪽에서 거두는 조건이 없으므로" 발코니를 향으로 삼을 수 없다**고 명시.

**계층적 정향 규칙**: 국가는 대강대하, 도시는 주간도로, 단지는 주간도로 진출입구, **주택은 대문에서 향을 취한다(住宅從大門取向)**.

### 1-2. 견해 ② 거실 큰 창·발코니(採光面) — 한국·대만 현대 실무

- **한국(근곡풍수지리연구원)**: **1순위 = 거실 창이 바라보는 방향 = 향(向)**. 이유는 "거실이 집의 중심 생활 공간이며 기운의 주 유입 창구". 현관은 **2순위(보조)** — "아파트는 구조가 획일적이고 현관이 복도·승강기홀에 연결되어 실제 기운의 영향력이 제한적". 3순위 건물 전체 좌향은 "동별·라인별로 구분되어 개별 세대마다 판정 필요"
- **대만(행복공간)**: **"발코니(陽台)가 있으면 발코니 방위 우선, 없으면 주가 대문 기준"**이라는 명시적 우선순위
- **한국 실무**: **"동 출입구와 거실 베란다가 향한 쪽이 앞"**, **"현관과 거실이 반대 방향일 때는 베란다가 향한 쪽을 우선"**

### 1-3. 견해 ③ 건물 전체(大廈 대당 출입구) — 홍콩식 표준

- 측정 위치 = **"대하(大廈) 정대당(正大堂) 문 앞 정면에 서서"** 그 정면 도수를 재어 24산 판정
- **납기문이 건물 전체의 기운을 결정**하고, 현관(內路門)은 절기(截氣)·완충, 가문(家門, 세대 내부 문)은 **해당 세대의 국부 길흉만** 좌우
- 대만 칼럼도 2층 구조로 분리: **"대루(大樓) 대문은 건물 전체 운, 주가(住家) 대문은 그 집 식구의 운·건강·재운·문창위"** → 둘을 따로 측정

### 1-4. 방형·비방형 건물 판별식 (중국 대륙식)

- 방형 건물 3원칙: **"문이 양면에 있으면 양면이 향, 문이 암면에 있으면 암면이 향, 문이 양 끝에 있으면 양면이 향"**
- 비방형 건물: **"대문을 낸 쪽이 곧 향면(向面)"**
- **"입향(立向)은 어렵지 않으나 판향(判向)이 어렵다"** — 진짜 실력은 향면 판정에 있다
- 3단계: 누형(樓型) 인정 → 향면 확정 → **실외에서 나경으로 좌향 측정**

### 1-5. 문향(門向)과 옥향(屋向)이 다를 때 📖

**표준 처리 = 양반(兩盤) 병용 + 동원일기(同元一氣) 점검**

> 『심씨현공학』: **"옥향과 문향을 나란히 중히 여긴다(屋向與門向並重)"**, **"대문이 옆으로 난 경우에는 대문향과 정옥향을 써서 두 반을 합해 본다(大門旁開者, 則用大門向與正屋向, 合兩盤之)"**

**동원일기(同元一氣) 원칙**: 옥향이 **천원룡(天元龍)**이면 대문도 천원룡 위치에, **지원룡(地元龍)**이면 지원룡 위치에, **인원룡(人元龍)**이면 인원룡 위치에 있어야 한다. 이를 어긴 **이원문(異元門)은 신중히**, **왜문(歪門)·겸향문(兼向門)은 금물**.

### 1-6. 단독주택과 아파트의 차이

| 구분 | 단독주택 | 아파트·공동주택 |
|---|---|---|
| 납기문 | 자기 대문이 곧 납기문(3조건 자동 충족) | **단지·동 출입구**가 납기문, 세대 현관은 「가문(家門)」으로 국부 길흉만 |
| 향 판정 | 대문·향면 명확 | 대문·발코니·건물향 3중 후보 → 유파 분기 |
| 현실 제약 | 문향 선택 가능 | **"단원루 주민은 총문이든 자기 입호문이든 위치·방향을 자유롭게 선택할 수 없다"** — 그래서 문향의 결정력을 낮게 보는 회의론도 제기됨 |
| 한국 실무 | 대문·안채 기준 전통 방식 | 거실창·베란다 우선 |

### 1-7. 측정 위치

| 방식 | 서술 |
|---|---|
| **실내 중심에서 밖을 향해** | 옥내에서 바깥을 향해 서서 측정, **등 뒤가 좌(坐), 정면이 향(向)** |
| **실외에서 측정** | 3단계 판향의 마지막이 "**나경을 실내가 아닌 실외에서** 좌향 측정" |
| **건물 로비 정문 앞** | 홍콩식 — "대하 정대당 문 앞 정면" |
| **평면도 기하중심 → 입극규(立極規)** | "옥택 평면도에서 기하학적 방법으로 중심점 산출 → **입극규로 8궁·24산 분할**" (측정은 향면에서, 궁 분할은 중심에서) |
| **한국: 나경 4층(지반정침)** | "풍수 나침반은 360도를 15도씩 24방위로 나누며, **현공풍수는 4층만 사용, 이를 지반정침(地盤正針)이라 한다**" |

🚫 철근·승강기 등 실내 자기 간섭 때문에 실외에서 재라는 실무 조언은 **자주 언급되는 통념이나 1차 출처 확인 안 됨**. 다만 "나경재실외측량"이라는 명시 서술은 확보.

### 1-8. 다수설 판단과 앱 설계 권고

1. **전통·고전 기준으로는 ①(대문·납기문)이 명백한 다수설**이다. 심씨·중주파·팔택이 모두 문 기준이고, 현공 교재의 정향 계층 규칙도 "주택종대문취향"이다.
2. **현대 공동주택 실무로 좁히면 ②(발코니·거실 큰창) + ③(건물 납기문)의 2층 구조가 사실상 다수 관행**이다.
3. **가장 방어적이고 문헌 근거가 확실한 처리 = 심씨의 양반 병용**이다. **옥향(향면=발코니·채광면) 성반 + 문향(현관) 성반을 각각 세워 겹쳐 읽되, 재물·유동 판단은 문향/납기 쪽에, 인정(人丁)·정주 판단은 옥향 쪽에 가중**한다.

> **앱 권고**: 단일 정답으로 못 박지 말고 입력을 ㉮ 세대 향면(거실창·발코니) ㉯ 현관 방위 ㉰ 건물 로비 방위(선택) 셋으로 받고, **기본값 = ㉮(옥향)**, **동시에 ㉯ 문향 반을 부반(副盤)으로 출력**하는 이중 표기가 근거상 가장 안전하다.
> **예외**: 앞뒤 모두 발코니인 판상형(맞통풍) 세대는 중주파 논리상 **발코니를 향으로 삼을 수 없으므로 문향 우선**.

### 1-9. ⚠️ 기두(起頭)는 현공 개념이 아니다

기두는 **동사택·서사택 판정의 기준점**을 뜻하는 **팔택(八宅)·양택삼요 용어**다. "기두 또는 대문이 감·리·진·손이면 동사택, 건·곤·간·태면 서사택"으로 쓰인다.

🚫 "공동주택에서 기가 시작되는 곳 = 현관을 기두로 본다"는 **명제를 직접 서술한 1차 출처는 확인되지 않았다.** 오히려 확인된 한국 자료는 ㉮ 세대 전체는 **베란다 우선**, ㉯ 각 방은 **방문 기준 기두**로 서술한다.

> **기두는 현공비성의 입극·정향과 별개 체계다. 현공 성반 기동에 기두를 쓰면 유파 혼용이다.**

## 2. 중심(天心·立極點) 잡기

궁 분할의 기준점이므로 현공 절차의 일부다.

| 평면 유형 | 처리법 |
|---|---|
| 정방형·장방형·평행사변형 | **대각선 교점** = 중심(오황점, 五黃點) |
| 결각(缺角)이 **총면적 2% 이내** | **보각법(補角法)** — 결각을 채워 정형으로 만든 뒤 대각선 교점 |
| 결각 + 돌출 혼재 | **할보법(割補法)** — 깎고 채워 정형화 |
| **ㄱ자(L형)** | 도형 전체의 **기하 중심점**을 오황점으로 |
| **ㄷ자(U형)** | 기하 중심점 기준. **중심이 실외로 나가면 그 점에 가장 가까운 꺾임부(拐彎處)를 취함** |
| 복잡 부정형 | 4개 사각형으로 분할 → 각 중심 연결 → 사다리꼴 → 사다리꼴 중심 |
| 요철 보정 비율 | **볼록(凸)이 2/3 초과면 채워 정형화, 1/3 미만이면 잘라냄. 오목(凹)도 동일** |
| **결각·돌출의 정의** | **"오목하거나 볼록한 부분은 반드시 집 길이의 절반보다 짧아야 한다"** (凹或凸之處必是短於屋宅長度的一半) |

**궁별 결각의 의미**: 감(坎) 결각=차남·신장 / 진(震)=장남·담 / 리(離)=차녀·심장. 돌출은 해당 성격의 과잉. 화해는 **"한쪽은 채우고 한쪽은 덜어낸다(一補一泄)"**. 특히 **서남(여주인)·서북(남주인) 결각을 경계**.

🚫 발코니·확장부 산입 여부는 **명시 규정 확인 안 됨**.

> ⚠️ 2% 규칙, "절반 미만" 규칙, "1/3·2/3" 규칙은 **서로 다른 층위**다. 2%는 "무시하고 보각해도 되는 미세 결각", 1/3·2/3은 "정형화 시 채울지 깎을지", 1/2는 "결각으로 볼지 아예 다른 형태로 볼지"의 기준으로 읽는 것이 정합적이다. 🚫 세 규칙을 하나의 권위 문헌이 통합 제시한 사례는 확인 안 됨.

## 3. 감정 절차 표준

### 3-1. 확인된 절차 서술 3종

**㉠ 한국(현공풍수 실무)**
```
지세·형국 평가 → 나침반(지반정침) 측정 → 현재 운(元運) 확인
→ 운반·비성도 작성 → 격국 판단
```
"20년 주기로 운이 바뀐다 … 8운 시대에는 8운을 기준으로 방위를 측정하여 분석"

**㉡ 중국 교재식 7단계**
```
① 나경으로 옥택의 산향(山向) 확정
② 착공/건축 시기로 운반(運盤) 확정
③ 평면도상 기하학적 방법으로 중심점 산출
④ 입극규(立極規)로 8궁 및 24산 분할
⑤ 산성(山星)·향성(向星) 배포 (하괘/체괘 판별 포함)
⑥ 주위 형만(形巒, 당국 환경)을 평면도의 실제 8궁 구역에 대응
⑦ 성반 내 추길(趨吉) 관건을 찾아 조정(布局)
```

**㉢ 현공 4단계 요결**
```
배룡(排龍) → 안성(安星) → 석국(析局) → 조정(調整)
```

### 3-2. 궁별 판단 순서

> **향수(向首) → 좌산(坐山) → 성문(城門) → 삼차수(三叉水) → 수취처(水聚處) → 산봉(山峰)의 수악(秀惡)**

핵심 명제: **"향비성이 택운의 권세를 잡아, 한 집의 화복을 관장한다"**
(向飛星操控著宅運的權柄, 司控著一宅的福禍)

향성이 왕하면 전반이 왕하고, 향성이 쇠하면 전반이 쇠한다.

**성요 등급**: 삼길성(三吉星) = **일백·육백·팔백** / 흉성 = **이흑·오황·칠적** / 차성(次星) = 삼벽·사록·구자
**왕쇠 간이 척도**: **"숫자가 운반 중심수에 가까울수록 길하고, 멀수록 좋지 않다"**
**두 반의 역할**: **"산은 인정을 주관하고, 물은 재물을 주관한다(山主人丁, 水主財)"**

### 3-3. 통합 실무 절차

```
0. 사전     준공년·대수선 이력·평면도 확보
1. 외부형기  【형기】 도로·인접 건물·형살·수구·명당   ← 타 체계, 배경으로만
2. 향면판정  누형 인정 → 향면 확정                   ← 최대 쟁점(1장)
3. 나경실측  향면에서 도수 측정 → 24산 → 하괘/체괘 결정
4. 원운확정  준공년(+대수선) → 운반
5. 입극      평면 기하중심 산출(결각·돌출 보정) → 8궁·24산 분할
6. 배반      운반 → 산성반 → 향성반 (삼원룡 음양 순비/역비)
7. 격국판정  향수·좌산 왕쇠, 4대 격국, 반음·복음
8. 궁별판단  향수 → 좌산 → 성문 → 삼차수 → 수취 → 산봉
9. 형기대조  각 궁의 실제 지형·창·물·도로와 성요 대조(합국/실국)
10. 당운 왕쇠 + 유년 연성 대입
11. 결론·조정 문·주·조·침대 배치, 화해책 (단 화살력량유한, 化煞力量有限)
```

## 4. 운(運) 기준 — 반을 어느 해로 세우는가

### 4-1. 견해 ① 낙성년(준공·완공년) — 다수설

- **대만 성림학원(星林學苑)**: **"원운의 정의는 집이 다 지어진 해이지 이사 들어간 때가 아니다. 2017년 준공이면 8운택이고, 2024년(9운)에 매입해도 여전히 8운택 — 전면 재장식(改換天心)을 하지 않는 한."**
- **홍콩 구중덕(區仲德)**: **"대규모 개조가 없으면 기존 세대는 이전 원운의 지정을 유지한다"**
- 홍콩 입문 강의: "건축물의 낙성 연도를 파악해 해당 운기에 대응"

### 4-2. 견해 ② 기조년(起造年, 착공년)

고전 계열에서 **"택운은 기조년으로 정한다"**는 서술이 확인되나, 장중산(章仲山)·심씨 원전의 직접 인용 확보에는 실패. 🚫
실무상 착공~준공이 같은 운 안에 드는 경우가 대부분이라 ①과 충돌이 드물다. **운 경계년(예: 2023↔2024) 건물에서만 문제된다.**

### 4-3. 견해 ③ 입주년·장수년(裝修年) — 소수설

"건축 원운은 반천(搬遷, 이사) 또는 장수(裝修, 수리)의 원운으로 확정한다"는 견해. ①의 예외 조항(개환천심)이 **일반 규칙으로 확장된 형태**로 보이나, 해당 자료는 그 자체를 원칙으로 서술한다.

### 4-4. 개환천심(改換天心) — ①의 예외 규정

| 출처 | 조건 |
|---|---|
| 구중덕 | **대문 교체, 부뚜막(爐灶) 교체, 또는 전 세대 대장수** → 8·7운택을 9운택으로 전환 |
| 성림학원 | 가구 전부 반출 → 실내 전면 개조 → **중앙 조명·선풍기·중앙에어컨 등 중앙 설비 교체** → 택일하여 입주. **단, 나경 측정 결과 왕산왕향·쌍성회향이고 외부 고층·도로가 배합되어야 유효.** 외부 조건이 안 맞으면 **개조만으로는 무효** |
| 홍콩 실무 | 지붕을 열 수 없는 고층은 **대문 + 전 창문 교체 + 천장·벽·바닥 재시공**으로 동등 효과. 일부는 **중궁 바닥을 소량 파내어 재시공** |

### 4-5. ⚠️ 반론 — 환천심 불필요설(자동 환운)

명리사 소산(少山): **"8운루가 9운에도 8운루인가? 실례로 '환천심' 미신을 깨다"**

장중산·장대홍의 **"수조는 마땅히 천심정운에 합해야 한다(修造尤當合乎天心正運)"** 인용은 인정하되, **대공사 없이도 9운 비성반이 이미 발현된 실증 3건**을 제시한다.
① 원인불명 출혈: 9운반의 오황 배치가 설명, 8운반에는 없음
② 관재: 9운반 육·삼 조합이 예측대로 발현
③ 본인 거처가 운 전환 후 구자 영향으로 매체 노출 급증
**결론: 값비싼 개조 대신 당운 부합도를 냉정히 평가하라.**

### 4-6. 8운 건물에 9운 입주 — 실제 해석 ✅

**다수설 = "원운 반 유지 + 당운 왕쇠 대입"**

1. **반은 유지**: 개환천심이 없으면 8운반을 그대로 쓴다
2. **왕쇠는 당운 기준으로 재평가**: "20년 주기로 운이 바뀌므로 **현재 운을 기준으로** 방위를 분석", "숫자가 운반 중심수에 가까울수록 길" — 기준 숫자는 **당운수**. 따라서 9운에는 **8운반의 8이 퇴기(退氣), 9가 당왕(當旺), 1이 생기(生氣)**로 재해석
3. 실제 시장 자료도 이 방식: 2026년 택루 가이드가 **9운 기준으로 좌향 우열을 재배열**

**충돌 지점**: 소수설 ③(입주·장수 기준)과 반론 ⑤(자동 환운)를 따르면 **9운반을 새로 세워야** 한다. 즉 **"8운반+9운 왕쇠"(다수설)** vs **"9운반"(소수설)** 두 결과가 다르게 나온다.

> **앱 방침**: 기본값 = **준공년 기준 원운반 + 당운 왕쇠 대입**(다수설). 입력에 **대수선(전면 리모델링) 이력 연도**를 옵션으로 받아, 체크 시 **개환천심으로 간주하여 리모델링 연도 기준 반을 재계산**. 운 경계 근처 건물(예: 2023 준공)은 **착공/준공 어느 쪽이냐로 반이 달라짐**을 경고 문구로 노출. 자동환운설은 "소수 견해" 각주로만.

## 6. 한국 유파의 특징

### 확인된 사실

- **한국 현공은 대만 계열 직수입이 주류.** 최명우(사단법인 대한현공풍수지리학회 연구소장)는 **대만 현공 대가 종의명(鍾義明)의 제자**. 저서 『현공풍수』 구성: 1부 풍수지리 개요, 2부 현공풍수학 이론(28주제), **3·4부가 각각 7운·8운의 24좌향 해설집** — **운별 24좌향 해설 카탈로그 형식**이 한국 교재의 특징
- 다른 계열: 낭월 박주현 『신나는 현공풍수 입문편』
- **대학 평생교육 커리큘럼이 형기+팔택+현공 혼합**: 1~3주 형기(용·혈·사·수·형국) → 4~6주 인테리어풍수 → **7주 팔택(개인 길·흉방위)+택일** → 8~12주 현공(삼원구운·24산향·하괘·체괘·4국·산수분류·나경법·복음·지운법·기국) → 13·15주 **향궁·좌궁·중궁 통변**, 14주 **컴퓨터 일반지도·위성지도 좌향측정법**
- **현공을 단독으로 쓰지 않고 형세풍수와 병용**한다는 명시: "전통적 형세풍수와 함께 현공대괘풍수, 현공비성풍수를 활용하여 음양택을 감정"
- **나경 사용 관행**: 현공은 4층(지반정침)만 사용
- **좌향 판정에서 한국은 거실창·베란다 우선 경향이 뚜렷**(중화권 문 기준과 대비)
- **위성지도·컴퓨터 좌향측정을 정규 커리큘럼에 포함**한 점은 한국 교육의 실무적 특징
- 학술 연구 존재: 천인호(2007) 「양택풍수의 속성이 아파트가격에 미치는 영향」 — 결론: 풍수 속성이 아파트 가격과 정(+)의 상관

### 확인 안 됨 🚫

한국 현공이 **비성 산법·격국 판정 자체를 대만·홍콩과 다르게 하는** 교리적 차이가 있는지는 **문헌 근거 확보 실패**. 확인된 차이는 ㉮ 좌향 기준 관행 ㉯ 병용 체계(형세+팔택 혼합) ㉰ 층수 논거 ㉱ 교재 형식 수준의 **운용상 차이**다.

## 7. 등급화 — 업계 표준은 없다

### 확인된 것

**㉠ 성요 3등급**: 삼길성(일백·육백·팔백) / 흉성(이흑·오황·칠적) / 차성(삼벽·사록·구자)
**㉡ 왕쇠 거리 척도(준정량)**: **"숫자가 운반 중심수에 가까울수록 길하다"** — 당운수와의 거리로 순위화 가능
**㉢ 좌향 랭킹(연도·운 기준)**: 2026년 1위 좌서북향동남 > 2위 좌서향동(팔백 납입) > 3위 좌남향북(단, 배후 오황 회피 조건) / **회피군**: 좌동남향서북, 좌북향남
**㉣ 9운 2분류**: **왕재국(旺財局, 창업자에게 적합)** / **왕정국(旺丁局, 급여생활자에게 적합)** 두 유형만 인정
**㉤ 매수 판단 원칙**: "왕산왕향 또는 기본 길격 우선 선택, 사후 화해에 과도 의존 금지 — 화살력량유한"

### 확인 안 됨 🚫

- **100점 만점 채점표·A/B/C 등급표 형식의 정량 평가 체계**: 발견하지 못함. 중화권 검색에서도 "구체적 표준화 점수표나 수치 평가 시스템은 제공되지 않음"으로 확인
- 4대 격국(왕산왕향/상산하수/쌍성회향/쌍성회좌)의 **명시적 우열 서열을 한 문헌이 순위로 제시한 원문**: 확보 실패. 통상 알려진 서열은 있으나 **1차 근거 미확보 → 앱에 넣을 경우 별도 검증 필요**

> **앱 원칙**: 자체 점수화는 가능하되 **"업계 표준 점수표는 존재하지 않으며 이것은 자체 기준"**임을 반드시 명시한다.
